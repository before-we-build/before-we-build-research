# Before We Build Applications

This directory contains domain-specific and worldview-specific applications built on top of the universal **Before We Build (BWB)** research core.

## Principle of Separation

- **Universal Core (`wiki/`, `raw/`):** Contains the foundational ontology, the four-level compatibility architecture, latent-process hypotheses, and worldview-neutral safety constraints.
- **Applications (`applications/`):** Worldview-, community-, or product-specific specializations. They apply the core models to concrete life contexts, languages, pastoral needs, or interaction workflows.
