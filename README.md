# Before We Build

[English](wiki/start-here-en.md) · [Русский](wiki/start-here-ru.md) · [Українська](wiki/start-here-uk.md)

Before We Build is a research framework for any two people facing a serious decision together.
It helps them discuss their values and differences, work out what remains uncertain, and decide what to ask.

The framework starts with a value-moral foundation and draws on three typologies to form
hypotheses about strategic, operational, and tactical processes. Here, a type is a hypothesis
about a recurring way of perceiving and organizing experience. The framework does not classify personalities.
It does not score compatibility or predict how a relationship will turn out. Whether a natural predisposition
underlies that pattern is a separate research question. Innateness has yet to be established.

The first application developed from this framework is a Christian conversation map for
relationship and family discernment.

Browse the generated catalog in [index.md](index.md). See [raw/README.md](raw/README.md)
for how the project preserves its sources.

## Repository Organization

- **`wiki/`** is the peer-reviewed core knowledge base. Each active page has matching English, Russian, and Ukrainian versions.
- **`raw/`**: Immutable primary source texts.
- **`applications/`**: Domain and worldview specializations (e.g., [applications/biblical-compatibility/README.md](applications/biblical-compatibility/README.md)).
- **`research/`**: Empirical case studies, instruments, and academic outreach packets ([research/README.md](research/README.md)).
- **`protocols/`**: Modular research and typological analysis protocols ([protocols/index.md](protocols/index.md)).
- **`governance/`** holds ethics policies and legal review requirements ([governance/README.md](governance/README.md)).
- **`scripts/` and `tests/`** contain automated tests and consistency checks.
