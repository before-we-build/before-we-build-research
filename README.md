# Before We Build

[English](wiki/start-here-en.md) · [Русский](wiki/start-here-ru.md) · [Українська](wiki/start-here-uk.md)

Before We Build is a universal research framework for helping any two people
surface values, differences, uncertainty, and useful questions before they
make serious shared decisions. It uses a value-moral foundation and three
typological systems as cautious hypotheses about strategic, operational, and
tactical processes—not as personality verdicts, compatibility scores, or
predictions of a relationship's fate. In plain language, a type is a model
hypothesis about a pattern of perception and experience organization, not a
personality type. Whether such a predisposition has a natural basis remains a
research hypothesis rather than established innateness. Its first developed specialization is a
Christian conversation map for relationship and family discernment; that is an
application of the universal core, not the definition of the whole project.
