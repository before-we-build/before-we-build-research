# SKILL: Cross-System Construct Comparison

## Purpose

Compare terminology and construct claims across Big Five, MBTI, Socionics,
Psychosophy, and Temporistics without translating a person from one system
into another. The systems are non-equivalent and separately modeled; they are
not assumed to be empirically independent.

## When to use

- explain why similarly named constructs differ;
- document a source-attributed crosswalk as a contested claim;
- design a study of convergent, discriminant, or incremental validity;
- identify observations that two systems classify differently.

Do not use this skill to infer a Socionics code from MBTI letters, derive a
Psychosophy or Temporistics type from Big Five thresholds, or «validate» one
unvalidated typology through agreement with another.

## Comparison protocol

1. Name the exact system, school, construct, and version on each side.
2. Describe each construct in its own vocabulary before comparing it.
3. Separate:
   - source attribution;
   - project interpretation;
   - direct empirical evidence;
   - unresolved or contested mapping.
4. Compare observable indicators, measurement method, unit of analysis, and
   claimed scope.
5. List overlaps, mismatches, rival explanations, and data that could refute
   the proposed relation.
6. Prefer `no justified mapping` when the evidence does not support one.

## Output

```yaml
source_system: "MBTI"
source_construct: "reported INTJ result"
comparison_system: "Socionics"
mapping_status: "contested; no one-to-one conversion"
source_claims: []
possible_descriptive_overlaps: []
important_mismatches: []
alternative_explanations: []
empirical_evidence: []
what_cannot_be_concluded:
  - "the person's Socionics type"
  - "cross-system validation"
next_testable_question: "..."
```

## Measurement boundary

Big Five scores are continuous measures tied to a specific instrument and
norming sample. MBTI, Socionics, Psychosophy, and Temporistics codes cannot be
created from fixed Big Five cut-offs. A questionnaire overlap is not scenario
validation and agreement between labels is not proof of a common latent
mechanism.
