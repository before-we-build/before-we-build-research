# SKILL: scientific-narrative-intelligence-layer

## Purpose

Transform dry, academic, technical, or complex conceptual material into world-class popular science narratives that optimize simultaneously for scientific correctness, deep comprehension, organic curiosity, and narrative momentum without falling into vulgarization, clickbait, or pseudo-science.

## When to Use

- Writing public-facing explanations of complex Before We Build core concepts (e.g., latent processes, four-level compatibility architecture, epistemic calibration).
- Creating science communication articles, longreads, or outreach materials for educated non-specialists.
- Editing existing technical drafts to eliminate AI cliches, tune cognitive load, and increase reader retention.
- Verifying science communication drafts against epistemic drift using multi-persona simulation and OpenAI Codex CLI.

## Core Transformation

Convert:
- abstract formalism -> intuitive grounding -> concrete scenario -> causal model -> technical term -> explicit model limits
- passive exposition -> continuous curiosity trajectory: $Q_i \to \Delta K_i \to Q_{i+1}$ (answering the reader's question while opening a deeper paradox)
- uncalibrated certainty -> strict epistemic differentiation across the 5 BWB inference levels
- cognitive overload -> working memory compliance ($\le 4\pm 1$ active concepts) with rhythmic pacing

## Subagent Architecture (Antigravity Runtime)

1. `snil_architect`: Concept Graph DAG, Curiosity Map, and Narrative Blueprint.
2. `snil_explainer`: 5-step explanation protocol (intuition -> example -> model -> term -> failure boundary).
3. `snil_editor`: Cadence balancing, cognitive load management, voice crafting, and AI-cliche purging.
4. `snil_epistemic_auditor`: Epistemic invariants, certainty inflation veto, and external stress-testing via OpenAI Codex CLI (`codex exec -s read-only`).
5. `snil_reader_panel`: 5-persona reader simulation (Curious Generalist, Technical Reader, Skeptical Reader, Impatient Reader, Domain Expert) and Reader Drop-off Hazard Map modeling.
6. `Scientific Narrative Director`: Orchestration, debate arbitration, gating floors, and final synthesis.

## Quality Gating Floors (Scientific Popularization Score 0–100)

- If `Scientific Accuracy` < 8.0 -> max SPS = 60 (rejected).
- If `Epistemic Calibration` < 8.0 -> max SPS = 65 (rejected).
- If `Clarity` < 7.0 -> max SPS = 70 (rejected).
- If `Conceptual Understanding` < 7.0 -> max SPS = 70 (rejected).
- Publication threshold: SPS $\ge$ 85, with no drop-off hazard spikes $\lambda(s) > 0.40$.

## Rules

- Interest never trumps correctness: sensationalism or premature certainty is grounds for an immediate veto.
- Every analogy must include an explicit section: "Where this analogy breaks down".
- Never introduce a technical term before its mechanism has been made intuitive.
- Maintain the strict 5-level separation: (1) Whole Person, (2) Observable Trace & Pattern, (3) Model Typological Hypothesis, (4) Latent Process Hypothesis, (5) Natural Predisposition Hypothesis.
- Epistemic modesty regarding inner motives must never compromise safety boundaries or excuse abuse, coercion, or harm.
