# Scientific Narrative Intelligence Layer (SNIL) Specification & Architecture

## Overview
Scientific Narrative Intelligence Layer (SNIL) is an advanced multi-agent system designed to convert complex, dry, academic, technical, and conceptual material into world-class popular science texts optimizing simultaneously for:
1. Correctness (scientific & epistemic accuracy, non-negotiable priority)
2. Comprehension (deep conceptual grasp, mental models)
3. Curiosity (organic micro-discoveries, inquiry-resolution loops)
4. Narrative Momentum (irresistible pacing, retention)

Core Principle: "Every subsequent thought must either answer a question that arose in the reader's mind or create a new, even more interesting question."
Core Invariant: Interest never trumps scientific or epistemic correctness.

## 22 Specialized Agent Roles
1. Scientific Narrative Architect (Cognitive route, Concept Graph, Mental state transition)
2. Curiosity Architect (Information gaps, organic paradoxes, anomaly spotting)
3. Explanation Engineer (5-step protocol: intuition -> example -> causal model -> term -> boundaries)
4. Mental Model Agent (System dynamics, feedback loops, stocks & flows)
5. Analogy & Thought Experiment Agent (Isomorphic metaphors with explicit failure boundaries)
6. Concrete Example Agent (Observable real-world manifestations, experiments, case studies)
7. Counterintuitive Insight Agent (Shattering naive assumptions, emergent properties)
8. Socratic Question Agent (Simulating the active questioning mind of the reader)
9. Cognitive Load Agent (Working memory guard: 4±1 Cowan limit, overload prevention)
10. Pacing Agent (Cadence, rhythmic tension-release balancing)
11. Voice Agent (Feynman/Sagan-level calm, respectful intellectual dialogue; zero AI cliches)
12. Compression Agent (Information density without losing transitions or examples)
13. Epistemic Integrity Agent (Veto power against certainty inflation, correlation-causation conflation)
14. Evidence Agent (Citation pyramid: meta-analyses -> systematic reviews -> primary studies)
15. Skeptic Agent (Stress-testing arguments, circular reasoning checks, rival explanations)
16. Reader Retention Critic (Hazard curve modeling, drop-off probability aggregation)
17–21. Reader Simulators (Curious Generalist, Technical Reader, Skeptical Reader, Impatient Reader, Domain Expert)
22. Scientific Narrative Director (State orchestrator, debate arbitration, gating and scorecard)

## Runtime Mapping in Antigravity & Codex CLI
The 22 theoretical roles are clustered into 5 high-efficiency subagents:
- `snil_architect`: Concept Graph, Curiosity Map, Narrative Blueprint.
- `snil_explainer`: 5-step explanation engine, analogies with failure boundaries.
- `snil_editor`: Voice craft, cognitive load limits, pacing, AI cliche scrubbing.
- `snil_epistemic_auditor`: Epistemic invariants, BWB 5-level distinction, and OpenAI Codex CLI execution via `codex exec -s read-only`.
- `snil_reader_panel`: 5 reader persona simulations and Reader Drop-off Hazard Map.

## Gating Floors & Scoring
- If Scientific Accuracy < 8.0 -> SPS <= 60 (rejected)
- If Epistemic Calibration < 8.0 -> SPS <= 65
- If Clarity < 7.0 -> SPS <= 70
- If Conceptual Understanding < 7.0 -> SPS <= 70
Target: SPS >= 85 for publication.
