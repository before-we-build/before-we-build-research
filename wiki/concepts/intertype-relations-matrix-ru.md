# Матрица межтипных отношений

<!-- section:overview -->
## Обзор

Справочная страница о классах межтипных отношений в соционике. Это **не** эмпирически откалиброванная таблица баллов совместимости: названия отношений описывают внутримодельный тактический обмен информацией, а не гарантированные исходы отношений.

<!-- section:quick-reference-relation-classes-not-scores -->
## Краткий справочник: классы отношений, а не баллы

| Класс отношений | Краткое описание тактического механизма | Оговорка |
|-----------------|------------------------------------------|----------|
| Тождество | Одинаковая структура Модели A; лёгкое узнавание и общие слепые зоны | Один тип не означает полную совместимость |
| Дуальность | Взаимное дополнение ценностных слабых функций (`1↔5`, `2↔6`) | Не гарантирует «родственную душу» |
| Активация | Взаимная стимуляция ценностных функций | Воодушевление может переходить в перевозбуждение |
| Зеркальные | Общие ценности при перестановке ведущей и творческой функций | Сходные темы, разные акценты |
| Заказ / социальный заказ | Асимметричная активация суггестивной функции | Направление важно: роли заказчика и подзаказного различаются |
| Ревизия / контроль | Асимметричное давление на уязвимую функцию | Направление важно: роли ревизора и подревизного различаются |
| Деловые / сотрудничество | Координация сильных функций без глубокого восполнения слабых зон | Часто понятны в задаче, но не обязательно в близости |
| Миражные / иллюзорные | Частичный комфорт при нестабильном согласовании | Первоначальная лёгкость не означает устойчивого соответствия |
| Квазитождество | Сходные темы при несовпадении ценностей | На поверхности похожи, структурно различаются |
| Погашение / противоположные | Взаимное приглушение информационной инициативы | Не обязательно враждебны |
| Конфликт | Взаимное столкновение сильных и слабых функций с разными ценностями | Гипотеза высокого трения, а не неизбежный конфликт |
| Суперэго | Взаимное напряжение суперэго и формальность | На дистанции могут оставаться корректными |
| Родственные / сравнительные | Общая ведущая ориентация при расхождении ценностей | Узнавание без полного дополнения |
| Полудуальность | Неполное покрытие дополняющих функций | «Частичная дуальность» не откалибрована как «почти дуальность» |

## Статус количественной оценки

Проценты здесь не назначаются: Before We Build не калибровал классы соционических отношений по наблюдаемым результатам диад. Любая будущая оценка должна указывать:

- прогнозируемый результат;
- выборку и надёжность типирования;
- интервалы неопределённости;
- базовую линию для сравнения;
- метод калибровки.
