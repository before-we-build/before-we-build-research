# Typology Notation Registry

This document standardizes codes and explicitly attributed aliases. It does not declare the typologies scientifically validated, describe a person's character, or assign cognitive processes to positions. An alias is a historical label from a source tradition, not a claim that a person resembles its namesake.

<!-- section:4-output-rule -->
## 4. Output rule

1. Give the code first and then the attributed alias: `ФВЛЭ — “Гёте”`.
2. Author-created metaphors or descriptions do not replace the registered alias.
3. Any characteristic following the code requires separate evidence and hypothesis status; it does not become a canonical part of the type.
