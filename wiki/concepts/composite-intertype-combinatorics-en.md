# Combinatorics of Composite Intertype Structures

<!-- section:status -->
## Status

This page counts structurally possible code combinations across the three typological submodels within BWB's four-level architecture. The value-moral foundation is not a typological code and is not part of this count. The page does not count empirically confirmed forms of compatibility, predict marriage, or describe the number of real relationships.

The project maps Socionics to tactical information modelling, Psychosophy to operational organization of action, and Temporistics to strategic temporal or existential direction. These mappings and all type assignments remain hypotheses.

<!-- section:1-composite-profiles -->
## 1. Composite profiles

| System | Number of codes | Repository basis |
|---|---:|---|
| Socionics | 16 | sixteen code labels in Model A tradition |
| Psychosophy | 24 | permutations of four source aspects |
| Temporistics | 24 | permutations of four temporal aspects |

Selecting one code from each system produces `16 × 24 × 24 = 9,216` possible code triples. This is a combinatorial space, not 9,216 kinds of person or validated psychological categories.

<!-- section:2-pairs-of-profiles -->
## 2. Pairs of profiles

Let `N = 9,216` denote the number of code triples.

- If direction matters, `A → B` and `B → A` are separate structural records. Including `A → A`, there are `N × N = 84,934,656` directed records.
- If order does not matter and equal profiles are included, there are `N × (N + 1) / 2 = 42,471,936` unordered records.
- If equal profiles are excluded, there are `N × (N − 1) / 2 = 42,462,720` unordered records.

Direction matters in source traditions that distinguish roles such as benefit/request or supervision/revision. The count says nothing about whether those proposed relations are reliable or consequential.

<!-- section:3-objects-that-must-not-be-confused -->
## 3. Objects that must not be confused

| Counted object | Count | Meaning |
|---|---:|---|
| Composite profiles | 9,216 | one code from each of three systems |
| Directed profile pairs | 84,934,656 | ordered pair `A → B`, including equal profiles |
| Unordered profile pairs | 42,471,936 | set `{A, B}`, including equal profiles |
| Unequal unordered profile pairs | 42,462,720 | set `{A, B}` with `A ≠ B` |
| Directed relation-signature combinations | 9,216 | product of 16 × 24 × 24 relation positions, not person profiles |
| Combinations using 14 Socionics relation names | 8,064 | simplified product that hides direction in two asymmetric relation families |

The repeated number 9,216 describes different mathematical objects in the first and fifth rows.

<!-- section:4-inference-limits -->
## 4. Inference limits

The correct conclusion is limited to the arithmetic: given the current code sets, this many formal combinations can be generated. It does not establish “millions of scientific relationship types.” In particular:

1. Socionics relation classes are claims within a source tradition, not general life outcomes.
2. The repository's Psychosophy relation matrix is a structural working model whose labels require source verification.
3. A complete source-grounded Temporistics relation system has not been established; the repository matrix is a BWB reconstruction.
4. Typological combinations do not measure faith, character, fidelity, repentance, maturity, safety, or a divine decision about marriage.
5. Observed human pairs depend on population and selection, not only on code-space size.

<!-- section:5-research-use -->
## 5. Research use

The count shows why exhaustive narrative descriptions are not a validation strategy. Research should sample prespecified mechanisms and outcomes, test whether each layer adds information beyond simpler contextual models, and discard hypotheses that fail. Composite codes may organize records; they must not become numerical ratings or verdicts about a pair.
