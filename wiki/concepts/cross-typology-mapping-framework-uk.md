# Рамка міжтипологічного зіставлення

<!-- section:overview -->
## Огляд

Запропонований процес для експериментів із мостами між трьома типологічними системами (темпористикою, психософією, соціонікою) та поширенішими моделями рис. Ця сторінка фіксує архітектурні ідеї проєкту й підхід до емпіричної перевірки через опитування, а не симуляцію чи встановлений стандарт зіставлення.

## Міжсистемне зіставлення

<!-- section:socionics-mbti-common-but-disputed-approximation -->
### Соціоніка → MBTI (поширене, але спірне наближення)

| Соціоніка | Поширене наближення MBTI | Примітка |
|-----------|---------------------------|----------|
| ILE | ENTP | Поширене зіставлення у спільноті |
| LIE | ENTJ | Поширене зіставлення у спільноті |
| EIE | ENFJ | Поширене зіставлення у спільноті |
| IEE | ENFP | Поширене зіставлення у спільноті |
| ILI | INTP або INTJ | Спірно |
| LII | INTP або INTJ | Спірно |
| EII | INFJ | Поширене, але все одно приблизне |
| SEE | ESFP | Приблизно |

<!-- section:temporistics-mbti-hypothesized -->
### Темпористика → MBTI (гіпотеза)

Вимір часової рамки зіставляється з уподобаннями когнітивного стилю:

| Рамка темпористики | Основне уподобання | Вторинне |
|--------------------|---------------------|----------|
| Типи Теперішнього (1-4N) | Сенсорика (конкретне) | Se/Si |
| Типи Майбутнього (1-4F) | Інтуїція (абстрактне) | Ne/Ni |
| Типи Вічності (1-4E) | Рефлексія (Ni/Si) | Збалансоване |
| Типи Минулого (1-4P) | Орієнтація на пам'ять | Переважання Si |

**Підхід до зіставлення:** поєднання аспектів темпористики зіставляються з юнгіанськими дихотоміями:

- часовий фокус (P/N/F/E) → попередні ознаки орієнтації;
- щільність аспекту → уподобання S/N;
- роль аспекту → T/F і J/P.

<!-- section:psychosophy-mbti-hypothesized -->
### Психософія → MBTI (гіпотеза)

Чотириаспектна структура зіставляється через зважування функцій:

| Патерн психософії | Можлива подібність MBTI | Примітки |
|-------------------|--------------------------|----------|
| Переважання Логіки | Акцент на мисленні | Лише наближення |
| Переважання Емоції | Акцент на почутті | Лише наближення |
| Переважання Фізики | Акцент на сенсориці | Лише наближення |
| Переважання Волі | Акцент на судженні / агентності | Лише наближення |

## Приклад гіпотези для перевірки

<!-- section:combined-temporistics-socionics-predicts-satisfaction-better-than-either-alone -->
### Поєднання темпористики й соціоніки передбачає задоволеність краще, ніж кожна система окремо

- **Метод:** інтерв'ю та структуровані опитування на OASIS-platform із 200 реальними парами.
- **Метрика:** багатофакторна регресія з перехресною перевіркою.
- **Очікування:** перевірити, чи поліпшують об'єднані ознаки прогноз порівняно з базовими моделями однієї системи.

<!-- section:tooling-reference -->
## Довідка про інструменти

<!-- section:personanexus -->
### PersonaNexus

- **Призначення:** декларативний опис особистості зі зіставленням між моделями.
- **Основні можливості:** двоспрямоване OCEAN↔DISC↔Jungian, файли ідентичності YAML, успадкування архетипів.
- **Команда:** `pip install personanexus`
- **Приклад:** `personanexus personality jungian-to-traits --preset intj`

**Примітка аудиту:** перевірку постачальника й джерел цього набору інструментів у поточному репозиторії не завершено; посилання на інструменти слід вважати дослідницькими вказівниками.

<!-- section:oasis-platform-survey-interviews -->
### OASIS-platform (опитувальні інтерв'ю)

- **Призначення:** якісні дослідницькі інтерв'ю та збір опитувань.
- **Основні можливості:** допомога в голосових/текстових інтерв'ю, транскрибування й кодування кількома LLM, розгортання Docker, відповідність FAIR.
- **Встановлення:** `git clone https://github.com/oasis-surveys/oasis-platform && docker compose up`
- **Ліцензія:** Open Non-Commercial Research License v1.0.
