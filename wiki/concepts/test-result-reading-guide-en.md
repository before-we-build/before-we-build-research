# Test Result Reading Guide

Languages: **English** | [[test-result-reading-guide-ru|Русский]] | [[test-result-reading-guide-uk|Українська]]

Use this page as a **reading guide**, not as proof of final typing. In Before We Build, a test result is a **pilot hypothesis** that still needs comparison with observation, self-description, and possible alternatives. See [[main-idea-en]] and [[compatibility-level-boundaries-en]].

The result concerns a proposed type pattern of perception and experience organization, not a personality type. A natural predisposition is only a further hypothesis. See [[typology-reconceptualization-en]].

<!-- section:level-separation -->
## Level Separation

The current architecture has four levels, but typology tests address only
three of them. The value-moral foundation is not a type test and must be
examined through stated commitments, observed conduct, consent and safety,
and relevant worldview, domain, culture, power, and institutional context.

Read each typological system only at its own level:

- **Socionics** = **tactical** level only -> information modeling.
- **Psychosophy** = **operational** level only -> action organization.
- **Temporistics** = **strategic** level only -> temporal-existential orientation.

Do not treat one system as a translation of another. A result in one layer may clarify that layer without deciding the others.

No combination of these test results establishes value-moral
compatibility.

<!-- section:how-to-read-result -->
## How to Read a Result

If a result shows a single best match plus alternatives, read it as a ranked hypothesis set:

- **Top-1** = current leading candidate inside that test model.
- **Top-3** = the three most plausible candidates worth reviewing together.
- Nearby candidates often mean the profile is not sharply separated yet.

In practice, compare the Top-3 pages and ask which description best explains repeated patterns over time, not just mood or recent stress.

<!-- section:clarity-labels -->
## Clarity Labels

- **Low clarity** = weak separation between candidates. Treat the result as exploratory.
- **Moderate clarity** = usable working hypothesis, but still open to revision.
- **High clarity** = stronger signal inside this test, but still not final typing.

High clarity does **not** mean certainty. It only means the current test produced a cleaner internal pattern.

<!-- section:individual-result-not-pair-compatibility -->
## An Individual Result Is Not Pair Compatibility

An individual typology test ranks candidate descriptions for one respondent inside one model. It does not measure compatibility between two people, compatibility at any of the four levels, or the likely outcome of a relationship.

- Top-1 rank and clarity labels must not be converted into a pair percentage or compatibility score.
- Two individual profiles do not by themselves establish a pair mechanism, resource, tension, or outcome.
- Any pair-level hypothesis must be checked against evidence from both people, the chosen outcome, context, power, consent, safety, and plausible alternative explanations.

<!-- section:reading-composite-results -->
## Reading Composite Results

If you receive one result from each system, read them side by side but keep boundaries intact:

- Socionics result -> tactical hypothesis about information modeling
- Psychosophy result -> operational hypothesis about action organization
- Temporistics result -> strategic hypothesis about temporal-existential orientation

The combined profile may be useful as a broader hypothesis, but it should not erase level boundaries or become a numerical pair verdict.

<!-- section:practical-rule -->
## Practical Rule

Treat every test result as:

```text
test output -> provisional type hypothesis -> compare with Top-3 -> check clarity -> verify against repeated evidence
```

Prefer cautious wording: *likely*, *current best fit*, *working hypothesis*, *needs verification*.
