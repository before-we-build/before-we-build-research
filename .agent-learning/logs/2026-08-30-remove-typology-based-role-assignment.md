# Typology-based role assignment audit

The repository clarity migration found active agents that translated Socionics, Psychosophy, and Temporistics codes directly into ranked civilian and military role recommendations. The instructions described positions as strengths or weaknesses, proposed high/medium/low confidence from agreement with type, and assigned high-risk roles without validated evidence.

The project owner approved a repository-wide plan stating that a type is a model hypothesis and does not determine profession, safety, destiny, or outcome. The agents therefore require an evidence-first boundary: verified qualifications, work samples, constraints, informed preferences, and role-specific requirements govern career exploration; typology cannot select or exclude a person from military or other high-risk roles.
