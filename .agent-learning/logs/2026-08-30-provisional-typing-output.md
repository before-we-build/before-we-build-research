# Observation

Several active typing skills and agents converted rankings, self-report totals, interviews, or public behavior directly into a type code and confidence label. One public-figure protocol also treated moral, military, and career evidence as indicators of Psychosophy positions. These instructions obscured rival explanations and exceeded the evidence available to Before We Build.

# Resolution

Typing output is now explicitly provisional. Instruments may report their own raw scores, but a type code is only a research hypothesis accompanied by indicators, contrary evidence, alternative explanations, method limitations, and a non-inference boundary. Public-figure work may not infer morality, military ability, diagnosis, or private mental state from typology.
