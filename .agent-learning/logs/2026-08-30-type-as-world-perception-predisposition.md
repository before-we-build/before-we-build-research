# Observation

The repository often stated the negative boundary that a type is not a kind of
person, but it did not consistently state the owner's positive
reconceptualization: a type is a model hypothesis about a pattern of world
perception, experience structuring, or process organization. The possible
natural basis of such a predisposition was also not consistently separated
from established innateness.

# Resolution

Canonical documentation and agent instructions now distinguish the whole
person, observable patterns, type-pattern hypotheses, latent-process
hypotheses, and the further hypothesis of a natural predisposition. The latter
is explicitly unvalidated and must be compared with learning, role, culture,
state, stress, and context.
