# Universal Research Core Review

## Decision basis

The project owner explicitly confirmed:

- the research project should be universal;
- it should apply to any two abstract people;
- **value-moral level** (`ценностно-нравственный уровень`) is the preferred
  foundational-level name.

## Safety and governance checks

- [x] Does not make typological hypotheses sound proven.
- [x] Does not introduce deterministic compatibility rules.
- [x] Does not remove the Christian application or its theological caveats.
- [x] Keeps consent, coercion, abuse, dignity, and safety boundaries explicit.
- [x] Separates universal research claims from worldview-specific normative
  claims.
- [x] Does not treat generated output as primary empirical evidence.

## Approved patch notes

- Define Before We Build as the universal research core.
- Define Christian discernment as the first developed worldview/domain
  application.
- Rename the universal foundational level from spiritual-moral to value-moral.
- Retain spiritual language inside explicitly Christian pages.

## Follow-up

Future work should operationalize value-moral compatibility without producing
an automated moral-worth score and should test whether it predicts outcomes
beyond values inventories, attachment, conflict style, and social context.
